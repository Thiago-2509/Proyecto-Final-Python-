# Smart Training
## Descripcion 

Un sistema para personas que apenas inicican en el mundo del gimnasio para que asi puedan tener un seguimiento de sus ejercicios y progresos en el gym.
Creado con python y echo para funcionar en consola, se compone de un menu simple donde se pueden agregar ejercicios, buscar ejercicios, ver lso ejercicios de la semana y ver los resultados calculando su progreso, es un sistema facil de usar y para todo el publico de uso gratuito por el momento solo se tienen en funcionamiento del menu las opciones 1, 2 y 5 las otras dos opciones estan en proceso de creacion.
pensado como el entregable final para la clase de python en el sena y creado por mi, Santaigo Upegui Yepes

## Funcionalidades
Menu interactivo compuesto de:
- Dar la bienvenida al usuario 
- Agregar ejercicio del dia  ✅  Completado
- Ver historial semanal ✅ Completado
- Calcular progreso ⚠️ En proceso 
- Buscar ejercicio ⚠️ En proceso
- Salir ✅ Completado
